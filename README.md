## DSA in C++ (Semester 3 - Advanced Data Structures)

Welcome to the **DSA-IN-CPP-** repository! This project contains clean, structured C++ implementations of fundamental and advanced data structures and algorithms, specifically covering data structures such as stacks, queues.

---

## 💡 Key Features Covered

* **Stack Operations**: Push, Pop, Peek/Top, and Overflow/Underflow checking using both Arrays and Linked Lists.
* **Queue Variants**:
  * **Simple Queue**: Standard First-In-First-Out (FIFO) structure.
  * **Circular Queue**: Efficient space utilization using modular arithmetic.
  * **Deque (Double-Ended Queue)**: Insertion and deletion at both front and rear ends.
  * **Priority Queue**: Elements processed according to assigned priorities.
* **Expression Parsing**: Stack-based evaluation and conversion of expressions (`Infix ➔ Postfix` and `Infix ➔ Prefix`).
